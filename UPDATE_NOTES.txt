SwipeSort 0.3.0 — исправление интерфейса и первая локальная сортировка

Что исправлено:
- Полный список скриншотов доступен через вкладку «Разбор», категория по умолчанию «Все».
- Пустая тематическая категория больше не называется «Всё разобрано»: предложена кнопка «Показать все».
- Диагностика теперь в отдельном диалоге и не съедает рабочую высоту экрана.
- Экран папок — один прокручиваемый список, заголовок не вытесняет сетку.
- Настоящие скриншоты загружаются из MediaStore, а свайпы/очередь удаления работают по прежней схеме.

Что добавлено:
- Локальное OCR Tesseract4Android для русского и английского. Языковые данные rus+eng включены в APK.
- Классификация распознанного текста по тематическим правилам (это НЕ нейросетевое понимание изображения).
- Два режима OCR: тестовые 40 файлов и остальные файлы за один запуск. Длинная обработка требует открытого приложения.
- Сохранение категории и отметки «текст просмотрен» после каждого файла. Можно продолжить после перезапуска.
- Остановка OCR; уже сохранённые результаты остаются.

Что НЕ реализовано:
- Визуальное понимание фото без текста.
- Семантическая модель (кроме тематических словарей).
- Гарантированная длительная обработка при закрытом приложении (WorkManager пока нет).
- Профессиональные инструментальные Android UI-тесты на реальном телефоне.

Техническое:
- Kotlin / Jetpack Compose, API 35, версия 0.3.0 (versionCode 3).
- Зависимость Tesseract4Android 4.9.0 из JitPack, языковые данные rus/eng из локального Tesseract.
- Нет разрешения INTERNET; скриншоты остаются на телефоне.
- Обработка не удаляет файлы; физическое удаление только через системную корзину с подтверждением.

Установка поверх существующего Codespaces:
1) Загрузить архив SwipeSort-v0.3.0-patch.zip в корень проекта.
2) Выполнить в терминале:
   unzip -o SwipeSort-v0.3.0-patch.zip -d . && rm SwipeSort-v0.3.0-patch.zip && git add app settings.gradle.kts UPDATE_NOTES.txt && git commit -m "Fix gallery UI and add offline categorization" && git push
3) GitHub Actions -> последняя сборка -> Artifacts -> APK.
4) После установки открыть «Разбор», категория «Все», проверить загрузку файлов и свайпы.
5) Открыть «Категории», нажать «Проверить следующие 40», оценить реальные результаты сортировки перед запуском по всем 5 223 файлам.

ВНИМАНИЕ: исходный код переработан и локальные правила классификации протестированы, но Android APK и реальные жесты не были проверены на устройстве в этом окружении. Успешная сборка необходима, но сама по себе ещё не гарантирует корректность работы на телефоне.
