# SwipeSort — Android MVP 0.1

Нативное приложение на Kotlin + Jetpack Compose для ручного разбора скриншотов на Android 11+.

## Уже реализовано

- Поиск изображений, похожих по имени/папке на скриншоты, через MediaStore.
- Просмотр настоящих скриншотов с телефона, без передачи файлов на сервер.
- Виртуальные категории с ручным назначением.
- Свайп влево = в очередь удаления; вправо = оставить; вверх = отложить.
- Кнопки для тех же действий.
- Сохранение статусов и категорий между запусками (SharedPreferences).
- Просмотр категории, массовое добавление в очередь с подтверждением; защищены явно оставленные.
- Возможность вернуть снимок из очереди.
- Удаление только через системный запрос Android `MediaStore.createTrashRequest()` после отдельного подтверждения; максимум по 100 за один запрос.
- GitHub Actions workflow для сборки отладочного APK.

## Чего пока НЕТ (не маскируем под AI)

- Автоматического распознавания содержания скриншотов и OCR.
- Умного определения дубликатов.
- Жестов «отменить свайп» (состояние можно вернуть через карточку в категории).
- Возможности создавать произвольные новые категории.
- Фонового сканирования.

Стандартная категория всех изображений — «Без категории». Отнести изображение в тематическую можно вручную.

## Сборка через GitHub с телефона (без компьютера)

1. В браузере Android откройте `https://github.com/new` и создайте публичный репозиторий `swipesort-android`, поставив галочку `Add a README`.
2. В репозитории: **Code → Codespaces → Create codespace on main**. Если элементы не помещаются на экране, включите «Версия для ПК» в Chrome.
3. Скачайте ZIP-архив проекта из чата ChatGPT на телефон.
4. В открывшемся VS Code в браузере найдите панель **Explorer** (файлы). На папке проекта откройте контекстное меню **Upload...** (возможно понадобится «Версия для ПК») и загрузите ZIP-архив из загрузок телефона.
5. Откройте терминал Codespaces (меню ☰ → Terminal → New Terminal, либо верхнее меню Terminal).
6. Выполните команды (если имя ZIP другое, замените его):

```bash
unzip -o SwipeSort-Starter.zip -d .
rm SwipeSort-Starter.zip
git add .
git commit -m "Initial SwipeSort MVP"
git push
```

7. В обычном интерфейсе GitHub зайдите в репозиторий → вкладка **Actions** → **Build Android APK**. Дождитесь зелёной отметки.
8. Откройте успешный запуск → **Artifacts → SwipeSort-debug-APK**, скачайте архив, извлеките `app-debug.apk` и установите APK (при необходимости дайте браузеру/файловому менеджеру разрешение «Установка неизвестных приложений»).

**ВНИМАНИЕ:** первая сборка не была запущена и проверена в этой среде. Если GitHub Actions выдаст ошибку, приложите лог ошибки, чтобы исправить исходный код.

## Технические детали

- Android API: minSdk 30 (Android 11), targetSdk 35.
- Для полного чтения скриншотов требуется соответствующее разрешение на фото. При частичном доступе будут видны лишь разрешённые изображения.
- Далеко не все OEM-скриншоты однозначно распознаются по папке/имени. Результат поиска зависит от производителя и приложения-источника.
- При отказе от системного удаления данные останутся в очереди.
- Разрешение на доступ к интернету приложению не требуется.
- Отладочный APK подписан стандартным debug-ключом GitHub runner и **не предназначен для распространения в Google Play**.
