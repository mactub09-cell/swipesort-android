SwipeSort 0.2.0 — диагностическое обновление

ИЗМЕНЕНО:
1. Экран показывает Android API, фактические выданные разрешения и версию приложения.
2. После попытки чтения показывает количество доступных изображений и найденных скриншотов.
3. Показывает несколько примеров имён файлов для проверки правил определения скриншотов.
4. Если MediaStore ничего не возвращает или выдаёт исключение, отображает понятную диагностику.
5. Добавлены кнопки «Проверить снова» и «Разрешения Android».
6. Версия обновлена до 0.2.0 (versionCode 2).

ЭТА ВЕРСИЯ ЕЩЁ НЕ ДОБАВЛЯЕТ ИИ-КЛАССИФИКАЦИЮ. Она нужна для устранения проблемы доступа/сканирования.

Установка патча в уже созданный Codespaces:
- загрузить SwipeSort-Diagnostics-02.zip через «Отправка...»;
- выполнить в терминале:
  unzip -o SwipeSort-Diagnostics-02.zip -d . && rm SwipeSort-Diagnostics-02.zip && git add . && git commit -m "Add scanner diagnostics" && git push
- если debug APK не обновляется из-за подписи, удалить только приложение SwipeSort (это не удалит фотографии), установить новый APK из GitHub Actions.

Критерий проверки: на стартовом экране присутствует надпись "Диагностика v0.2.0", а цифры для MediaStore и permissions помогают локализовать причину пустой галереи. Сборка APK в данном окружении не выполнена — нужно проверить GitHub Actions.
